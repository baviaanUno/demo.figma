## Commit Guidelines
Every commit must be a conventional commit. Please follow the guidelines below when committing changes to the repository.

- Use the present tense
- Use the imperative mood
- Limit the subject line to 50 characters or less
- Capitalize the subject line
- Do not end the subject line with a period
- use Feat: for new features
- use Fix: for bug fixes

## Security guidelines
- Never commit secrets or sensitive information (e.g., passwords, API keys, private keys) to the repository. Use environment variables or secure vaults to manage sensitive data.
